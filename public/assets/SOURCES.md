# Asset sources

- `shaft.png`: generated specifically for Downstack from the approved monochrome computer-shaft concept, using OpenAI image generation. It is decorative artwork, not a screenshot or a source-code rendering. Its original generation prompt is embedded in PNG metadata.
- `elevator.svg`, `rocket.svg`, `stop.svg`: original small pixel icons authored for Downstack. Text and controls are never rasterized.
- `../fonts/press-start-2p.ttf`: Press Start 2P by CodeMan38, downloaded from https://github.com/google/fonts/tree/main/ofl/pressstart2p. The SIL Open Font License is included in `../fonts/OFL.txt`.
