# Gameplay direction

Approved through the user's request: "let's change the font of the prompt ... to match the other pixel fonts. after that, refactor the code base and push results" following the charcoal/warm-white/vermilion gameplay and reveal concepts.

THESIS: One prompt, one answer, one descent. An arcade inside a computer rather than a developer dashboard.

OWN-WORLD: Near-black, warm white, gray, and a single vermilion accent. Self-hosted Press Start 2P includes the prompt. Raster computer machinery stays at the left; authored pixel elevator and reward icons remain small.

STORY: Read, think, submit; see the startup rank and meter gain; descend; explicitly start the next clock. Seven questions end in a daily result.

FIRST VIEWPORT: Desktop left shaft and right playfield. Wordmark and daily identity above question progress, prompt, numeric 25s segmented timer, labeled input, Submit, and previous-answer receipt. Mobile exposes current depth and an optional full vertical map instead of shrinking the desktop artwork.

FORM: seed: none (pinned). User selected pixel UI, startup ranks, charcoal/warm-white/vermilion, and the displayed gameplay/reveal layout, then explicitly requested the prompt's pixel font and implementation/push.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
